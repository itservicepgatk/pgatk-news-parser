# Пинский государственный аграрно-технический колледж имени А.Е.Клещева - News Parser & Data Scraper

Этот репозиторий содержит скрипты для автоматического парсинга новостей из Telegram-канала колледжа.

## Состав
- `telegram_parser.py`: Основной скрипт парсера новостей. Загружает новости из Telegram, скачивает картинки (и применяет умную обрезку 16:9 с распознаванием лиц через OpenCV), тегирует новости и обновляет `telegram_news.json`.
- `telegram_news.json`: База данных распарсенных новостей.
- `telegram_parser_test.py`: Скрипт для тестирования изменений без прямого обновления основной базы.
- `local_scheduler.py`: Скрипт для локального запуска парсера в фоновом режиме каждые 30 минут.

## Использование
Парсер запускается автоматически каждые 30 минут через GitHub Actions (настраивается в `.github/workflows/update_news.yml`) и сохраняет полученные данные в `telegram_news.json`.

Вы также можете запустить автоматический парсинг локально с помощью:
`python local_scheduler.py`

Для умной обрезки изображений требуется OpenCV:
`pip install -r requirements.txt`
